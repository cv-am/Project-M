# ExploreEase – Travel & Tourism Website (by Mahak🌸🌹)
A responsive frontend-only travel website created with HTML5, CSS3, vanilla JavaScript and Bootstrap 5.

## Features
- Responsive navigation bar with mobile menu
- Travel hero section and trip search/filter by destination and travel style
- Destination cards and curated sample tour packages
- Package detail modal
- Hotel/stay showcase
- Contact form with client-side validation
- Responsive layouts for mobile, tablet and desktop

## Project structure
- `index.html` – page structure and content
- `style.css` – custom styling and responsive breakpoints
- `script.js` – search/filter, modal, form validation and navigation interactions
